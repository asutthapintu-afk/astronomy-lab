# ห้องปฏิบัติการดาราศาสตร์เสมือน (Virtual Astronomy Lab)

เว็บแอปตัวจำลองแบบโต้ตอบ 11 ปฏิบัติการ สำหรับรายวิชา 2015326 ดาราศาสตร์ และ 2015231 ดาราศาสตร์และอวกาศสำหรับครูวิทยาศาสตร์
หลักสูตรสาขาวิชาฟิสิกส์ มหาวิทยาลัยราชภัฏมหาสารคาม

**เปิดใช้งาน:** https://asutthapintu-afk.github.io/astronomy-lab/

1. แบบจำลองระบบสุริยะ
2. วงโคจรของดาวเคราะห์และกฎของเคปเลอร์
3. ระบบพิกัดพื้นฐานและฤดูกาล
4. การเคลื่อนที่ของทรงกลมท้องฟ้า
5. การเคลื่อนที่ของดวงอาทิตย์
6. เฟสของดวงจันทร์
7. การอ่านแผนที่ดาวและการดูดาวเบื้องต้น
8. กล้องโทรทรรศน์
9. แผนภาพเฮิรตซ์สปรุง–รัสเซลล์
10. ดาวคู่อุปราคา
11. ดาวแปรแสงและการวัดระยะทาง

ทุกปฏิบัติการมีวิธีการทดลอง ทฤษฎีโดยย่อ (อ้างอิง OpenStax *Astronomy 2e*) และใบงานบันทึกผล รวมเป็นรายงานดาวน์โหลดได้
คำตอบของนักศึกษาเก็บในเบราว์เซอร์ของแต่ละคน (localStorage) ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์

เว็บเป็นไฟล์ static ล้วน ไม่ต้องติดตั้งหรือ build

ข้อมูลตำแหน่งดาวและเส้นกลุ่มดาว: [d3-celestial](https://github.com/ofrohn/d3-celestial) (BSD-3-Clause)
